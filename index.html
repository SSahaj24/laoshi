Quick Reference

Type pinyin to see if you've learned the character for it.

Type each syllable separated by a space. Put the tone number (1–4) right after the letter that carries the mark — not just at the end.
三十五 → sa1n shi2 wu3 (sān shí wǔ).
二 → e4r, not er4. 零 → li2ng, not ling2.
Typed tone marks (āáǎà…) also work, e.g. sān shí wǔ.
For ü, type v — 綠 → lv4 (lǜ).
Homophones: characters that sound alike but differ in tone, shown together — e.g. 七氣起期 → qi1 qi4 qi3 qi2. Combo: two random characters mashed together, real word or not. Both show a real word each character is used in ("Used in:") alongside the answer. Mistakes: everything you've gotten wrong or skipped, from any mode — answer one correctly and it drops off the list. Homophone/Combo mistakes still show their "Used in:" examples too.
